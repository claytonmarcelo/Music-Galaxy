# Assets do Music Galaxy

Esta pasta contém os assets do aplicativo (ícones, splash screens, fontes, imagens).

## Ícones

Para desenvolvimento, você pode usar os ícones padrão do Expo. Para produção, substitua por:

- icon.png - Ícone principal do app (1024x1024)
- android-icon-foreground.png - Foreground para Android (1024x1024)
- android-icon-background.png - Background para Android (1024x1024)
- android-icon-monochrome.png - Monochrome para Android (1024x1024)
- favicon.png - Favicon para web (48x48)

## Como gerar ícones

Use o Expo Icon Tool: https://icon.expo.fyi/

Ou execute:
```bash
npx expo-icon-maker@latest
```
